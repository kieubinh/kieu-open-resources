Hash Map — đổi bộ nhớ lấy thời gian

Dấu hiệu

"Có cặp/phần tử nào thoả…", cần tra cứu nhanh "đã gặp chưa", đếm tần suất, gom nhóm.

Ý tưởng

Thay vòng lặp thứ hai bằng một lần tra cứu O(1) trong dict/set.

Độ phức tạp

Thời gian O(n), bộ nhớ O(n).

def two_sum(nums, target):
    pos = {}                     # giá trị -> chỉ số
    for i, x in enumerate(nums):
        if target - x in pos:
            return [pos[target - x], i]
        pos[x] = i

Two Pointers — hai đầu tiến lại gần nhau

Dấu hiệu

Mảng đã sắp xếp (hoặc sắp xếp được), tìm cặp/bộ ba, so sánh hai đầu, đảo chuỗi.

Ý tưởng

Mỗi bước loại bỏ được một đầu chắc chắn không cho kết quả tốt hơn.

Độ phức tạp

Thời gian O(n), bộ nhớ O(1).

def max_area(h):
    l, r, best = 0, len(h) - 1, 0
    while l < r:
        best = max(best, min(h[l], h[r]) * (r - l))
        if h[l] < h[r]:
            l += 1               # cột thấp giới hạn diện tích
        else:
            r -= 1
    return best

Sliding Window — cửa sổ co giãn

Dấu hiệu

"Chuỗi con / mảng con liên tiếp dài nhất / ngắn nhất thoả điều kiện…"

Ý tưởng

Mở rộng bên phải; khi cửa sổ vi phạm điều kiện thì thu hẹp bên trái.

Độ phức tạp

Thời gian O(n), bộ nhớ O(số ký tự khác nhau).

def longest_unique(s):
    last, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        if last.get(ch, -1) >= left:
            left = last[ch] + 1  # nhảy qua ký tự trùng
        last[ch] = right
        best = max(best, right - left + 1)
    return best

Prefix Sum — tổng dồn để trả lời nhanh

Dấu hiệu

"Tổng của đoạn [i, j]", "có bao nhiêu mảng con có tổng bằng k" (kể cả số âm).

Ý tưởng

sum(i..j) = P[j] − P[i−1]. Kết hợp Hash Map để đếm các P đã gặp.

Độ phức tạp

Thời gian O(n), bộ nhớ O(n).

def subarray_sum(nums, k):
    count, s, ans = {0: 1}, 0, 0
    for x in nums:
        s += x
        ans += count.get(s - k, 0)
        count[s] = count.get(s, 0) + 1
    return ans

Binary Search — tìm vị trí "đúng" đầu tiên

Dấu hiệu

Dữ liệu sắp xếp, hoặc câu hỏi kiểu "giá trị nhỏ nhất sao cho … vẫn làm được" (tìm kiếm trên đáp án).

Ý tưởng

Viết hàm ok(x) có dạng Sai…Sai Đúng…Đúng, rồi tìm chữ Đúng đầu tiên.

Độ phức tạp

O(log M) lần gọi ok(x).

def first_true(lo, hi, ok):
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid             # mid có thể là đáp án
        else:
            lo = mid + 1
    return lo

# Koko: tốc độ ăn nhỏ nhất kịp trong h giờ
# first_true(1, max(piles),
#   lambda k: sum((p + k - 1) // k for p in piles) <= h)

Monotonic Stack — "phần tử lớn hơn tiếp theo"

Dấu hiệu

"Bao lâu nữa thì gặp giá trị lớn/nhỏ hơn", ngoặc hợp lệ, hình chữ nhật lớn nhất.

Ý tưởng

Ngăn xếp giữ các chỉ số "đang chờ câu trả lời". Phần tử mới giải quyết những phần tử nhỏ hơn nó.

Độ phức tạp

O(n): mỗi phần tử vào và ra ngăn xếp đúng một lần.

def daily_temps(t):
    ans, st = [0] * len(t), []
    for i, x in enumerate(t):
        while st and t[st[-1]] < x:
            j = st.pop()
            ans[j] = i - j
        st.append(i)
    return ans

07

BFS — đường ngắn nhất theo số bước

Dấu hiệu

"Ít bước nhất", lan theo từng lớp (cây theo tầng, lưới, cam thối lan).

Ý tưởng

Hàng đợi xử lý hết lớp hiện tại rồi mới sang lớp tiếp theo; đánh dấu đã thăm khi đưa vào hàng đợi.

Độ phức tạp

O(V + E).

from collections import deque

def bfs(start, goal, nbrs):
    q, seen, steps = deque([start]), {start}, 0
    while q:
        for _ in range(len(q)):   # một lớp
            u = q.popleft()
            if u == goal:
                return steps
            for v in nbrs(u):
                if v not in seen:
                    seen.add(v)
                    q.append(v)
        steps += 1
    return -1

DFS / Backtracking — thử, đi sâu, quay lui

Dấu hiệu

"Liệt kê tất cả" tập con, hoán vị, tổ hợp; tìm đường trong lưới.

Ý tưởng

Chọn → đệ quy → bỏ chọn. Cắt nhánh sớm khi chắc chắn không ra kết quả.

Độ phức tạp

Tập con: O(n · 2ⁿ).

def subsets(nums):
    res = []
    def bt(start, path):
        res.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])     # chọn
            bt(i + 1, path)          # đi sâu
            path.pop()               # quay lui
    bt(0, [])
    return res

Heap / Top-K — giữ lại K phần tử tốt nhất

Dấu hiệu

"K lớn nhất / nhỏ nhất / thường gặp nhất", trộn nhiều danh sách đã sắp xếp.

Ý tưởng

Min-heap kích thước k: phần tử nhỏ nhất trong heap chính là phần tử lớn thứ k.

Độ phức tạp

O(n log k), bộ nhớ O(k).

import heapq

def kth_largest(nums, k):
    h = []
    for x in nums:
        heapq.heappush(h, x)
        if len(h) > k:
            heapq.heappop(h)     # bỏ phần tử nhỏ nhất
    return h[0]

Quy hoạch động — bài lớn từ bài nhỏ

Dấu hiệu

"Số cách", "nhỏ nhất / lớn nhất", lựa chọn ở bước này ảnh hưởng bước sau, bài con lặp lại.

Ý tưởng

Định nghĩa dp[trạng thái], viết công thức chuyển, chọn thứ tự tính sao cho bài con có trước.

Độ phức tạp

Số trạng thái × chi phí mỗi lần chuyển. Coin Change: O(amount · số loại xu).

from math import inf

def coin_change(coins, amount):
    dp = [0] + [inf] * amount    # dp[a]: số xu ít nhất
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] < inf else -1

Khoảng & Tham lam — sắp xếp rồi quét

Dấu hiệu

Danh sách [bắt đầu, kết thúc]: gộp, đếm chồng lấn, xếp lịch; "bỏ ít nhất bao nhiêu".

Ý tưởng

Sắp xếp theo điểm đầu (hoặc điểm cuối), rồi quyết định tại chỗ với khoảng gần nhất.

Độ phức tạp

O(n log n) cho bước sắp xếp.

def merge(iv):
    iv.sort()
    out = [iv[0][:]]
    for s, e in iv[1:]:
        if s <= out[-1][1]:          # chồng lấn
            out[-1][1] = max(out[-1][1], e)
        else:
            out.append([s, e])
    return out

Union-Find — gom nhóm các phần tử liên thông

Dấu hiệu

"Có bao nhiêu nhóm", "thêm cạnh này có tạo chu trình không".

Ý tưởng

Mỗi nhóm có một đại diện; gộp hai nhóm bằng cách nối đại diện.

Độ phức tạp

Nén đường đi: O(log n) mỗi thao tác (khấu hao); thêm gộp theo hạng thì gần như O(1).

parent = list(range(n))

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]   # nén đường đi
        x = parent[x]
    return x

def union(a, b):
    ra, rb = find(a), find(b)
    if ra == rb:
        return False             # đã cùng nhóm → chu trình
    parent[ra] = rb
    return True

Luyện cùng AI mà không học vẹt

AI giải hộ bạn trong 3 giây, nhưng như vậy bạn không học được gì. Hãy dùng AI như một người hướng dẫn: gợi ý từng chút, bắt bạn tự giải thích.

  1. Tự làm 20–25 phút trước. Viết ra: bài thuộc mẫu nào, vì sao, và một ví dụ nhỏ tự tạo.
  2. Xin gợi ý, không xin lời giải. Mỗi lần chỉ hỏi một gợi ý.
  3. Tự viết code, rồi nhờ AI tìm trường hợp biên làm code sai.
  4. Giải thích lại cho AI như đang dạy người khác. AI chấm xem bạn hiểu đúng chưa.
  5. Làm lại sau 3 ngày, không xem bài cũ.
Prompt 1 — Gợi ý từng bước
Mình đang giải LeetCode {số}. Đừng đưa lời giải hay code. Hãy cho mình đúng MỘT gợi ý nhỏ nhất để đi tiếp. Mình sẽ hỏi tiếp nếu vẫn kẹt.
Prompt 2 — Nhận dạng mẫu
Đây là đề bài: {dán đề}. Mình nghĩ nó thuộc mẫu {tên mẫu} vì {lý do}. Lập luận của mình đúng hay sai ở đâu? Chưa cần nói mẫu đúng là gì.
Prompt 3 — Tìm trường hợp biên
Đây là code của mình: {code}. Đừng sửa code. Hãy liệt kê 5 input có khả năng làm code sai (mảng rỗng, phần tử trùng, số âm, giá trị lớn…) và để mình tự chạy thử.
Prompt 4 — Kiểm tra mức hiểu
Mình sẽ giải thích lời giải bằng lời của mình: {giải thích}. Hãy hỏi mình 3 câu để kiểm tra mình hiểu thật hay chỉ nhớ. Sau đó chấm điểm 1–10 và chỉ ra chỗ còn mơ hồ.
