# Agent instructions

## LeetCode problem-solving videos

For Kieu Studio LeetCode videos, use `.agents/skills/kieu-leetcode-video/SKILL.md` and the canonical skill at `skills/kieu-leetcode-video/SKILL.md`. Never claim a guide-voice MP4 is publish-ready. Verify source facts and all examples before rendering.

## Resource discovery

When development needs datasets, models, frameworks, skills, tools or reusable assets, use `kieu-resource-discovery` and search the configured Kieu Resources service first. CLI: `kieu-resource`; MCP: `kieu-resource-mcp` when explicitly configured. Use the separate write credential for candidates, central manifests and evaluations. Ask before large downloads, costly work, private-data processing or training. See the shared skill for the full workflow.
