#10 Regular Expression Matching

Một dấu * có nhiều lựa chọn. Chia nhỏ thành câu hỏi dfs(i, j), rồi nhớ câu đã trả lời.

Đề bài trong 1 câu

Ghép s với p, phải khớp toàn bộ s. . = 1 ký tự bất kỳ; x* = 0 hoặc nhiều ký tự x liền nhau.

s="aa" p="a" → falses="aa" p="a*" → trues="ab" p=".*" → true

Chìa khoá

Bài toán lớn = nhiều câu hỏi nhỏ (i, j): “s[i:] có khớp p[j:] không?”. Cùng một câu hỏi chỉ trả lời một lần (@cache).

Hình minh hoạ · hai lựa chọn khi gặp x* và bảng nhớ

Cách làm

  1. Hết p (j == len(p)) → chỉ đúng khi cũng hết s.
  2. first = s[i] khớp p[j] (hoặc p[j] là .).
  3. Nếu p[j+1] là *: thử 0 lần (dfs(i, j+2)) hoặc dùng thêm 1 lần (first and dfs(i+1, j)).
  4. Ngược lại: first and dfs(i+1, j+1).

Code Python 3 (đã chạy thử trên ví dụ của đề)

from functools import cache

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        @cache
        def dfs(i: int, j: int) -> bool:
            if j == len(p):
                return i == len(s)
            first = i < len(s) and (s[i] == p[j] or p[j] == ".")
            if j + 1 < len(p) and p[j + 1] == "*":
                return dfs(i, j + 2) or (first and dfs(i + 1, j))
            return first and dfs(i + 1, j + 1)
        return dfs(0, 0)

Độ phức tạp

Thời gian O(m·n)Bộ nhớ O(m·n)

m = len(s), n = len(p): tối đa ~m·n trạng thái, mỗi trạng thái giải một lần.

Bẫy hay gặp

  • Quên x* có thể khớp 0 ký tự: "aab" với "c*a*b".
  • Đọc p[j+1] mà không kiểm tra j + 1 < len(p).
  • Không nhớ kết quả → số nhánh tăng rất nhanh.
